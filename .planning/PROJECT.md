# TrueCharts

## What This Is

TrueCharts is a catalog of about 800 Helm charts for running self-hosted applications on Kubernetes. Almost every chart is a thin wrapper around one shared library chart, `common`, which renders all Kubernetes objects from values. This repository holds the charts, the `common` library, its unit-test harness (`common-test`), and the CI and release tooling.

## Core Value

Every chart in the catalog installs and runs with secure defaults, and a change to `common` does not break the charts that depend on it.

## Context

- Brownfield repository. The codebase map is in `.planning/codebase/` (ARCHITECTURE, STACK, STRUCTURE, CONCERNS, TESTING, CONVENTIONS, INTEGRATIONS), mapped at commit `c71e810c627`.
- Application charts under `charts/stable/` and `charts/incubator/` contain only `values.yaml` and an optional `common.yaml`. Changes to `common` affect all of them.
- The `common` schema is the source of truth for values. `values.schema.source.json` is bundled into `values.schema.json`.
- Known concerns (from CONCERNS.md): stubbed `common` templates, a disabled dependency lint in `tc-lint.sh`, and 262 charts pinned to `latest` tags.

## Constraints

- **Compatibility**: Helm 3.14 must keep working for `common`, and the latest Helm 4 is the development target — AGENTS.md toolchain section
- **Kubernetes**: `kubeVersion >=1.33.0-0` — AGENTS.md
- **Backwards compatibility**: renamed or removed values keys, or changed object names and selectors, are breaking changes and need a major version bump — common-library instructions
- **Versioning**: chart `version` bumps follow SemVer, once per PR into `master` — AGENTS.md
- **Security**: no default passwords, credentials only in Secrets, images pinned by digest — AGENTS.md security section
- **Tooling**: `charts/library/common-test` stays at version `1.0.0` — common-library instructions

## Key Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| Shared `common` library chart, charts only set values | One place to fix security and rendering across ~800 charts | ✓ Good |

| Dependencies injected by `common`, not Helm subcharts | Keeps credentials in Secrets and rendering in one place | ✓ Good |
| Pod Security Standard "restricted" as the default | Secure by default; relaxing is an explicit per-chart choice | ✓ Good |
